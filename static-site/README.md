# Статический сайт Милены Дмитриевой

Это самостоятельная HTML/CSS/JavaScript-версия каталога, добавленная рядом с существующими Next.js/FastAPI/3D-приложением. Старый код не удалён и не изменён.

## Запуск

Откройте `static-site/index.html` в браузере. Никаких npm, Docker, API или базы данных не требуется.

## Наполнение

Каталог находится в массиве `artworks` в нижней части `index.html`.

Начальные две записи:
- «Дом» — 2024, пастель, 84 × 120 см;
- «Уверенность в выборе» — пастель, 75 × 110 см, год **не подтверждён**, поэтому не опубликован.

**Обязательно перед публикацией:** заменить отсутствующие фотографии в `static-site/images/` реальными файлами `dom.webp` и `confidence-in-choice.webp`. На текущем этапе вместо них показывается надпись, чтобы сайт не выдавал демонстрационные SVG за реальные произведения. Заполнить/проверить точные цены и статусы наличия по инвентарю, а также добавить остальные работы из актуального портфолио. Без явного подтверждения цены показываются «По запросу».

Поля карточки:
```js
{
 slug: "dom",
 title: "Дом",
 series: "Город",
 year: 2024,
 technique: "Пастель",
 width: 120,  // ширина в см
 height: 84,  // высота в см
 image: "images/dom.webp",
 description: "...",
 price: null, // число в рублях, если подтверждено
 available: null
}
```

## Контакты

Сайт использует `mailto:ivankalent@gmail.com` и не собирает персональные данные на сервере. Покупки обрабатываются вручную после обращения. Если понадобится онлайн-оплата, её можно добавить платёжной ссылкой без бэкенда.

## Важно

Папка `static-site/` не подключена к продакшен-домену. Для публикации настройте Nginx на статическую директорию или разместите её на статическом хостинге. Не переключайте `milena-dm.ru` без проверки изображений, фактических цен, DNS и существующих ссылок `/works`.
